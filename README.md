# 烛龙 Zhulong · Windows 系统监控托盘

> 察于幽冥 · 睁眼为昼 闭眼为夜
> A personal Windows system tray monitor — watches the invisible metrics (commit charge, CPU, disk IO), auto-disposes known memory leaks, and tells you before things break.

## 新版当前进度（2026-11-14）

新版是项目当前的运行和开发入口。新版使用自己的程序目录、配置与数据库，旧版代码与历史可留档。运行入口为独立目录的 Zhulong.exe。0.2.7 的程序和系统托盘使用 C 朱印，贴边挂件顶部使用 A 玉龙，详见[桌面运行说明](desktop/README.md)。

进程CPU显示为“占整机CPU”，与旧psutil每核100%的数字不同。工作集排行与私有commit分开，磁盘容量占比也不代表IO利用率。套餐重置依赖来源快照，不能根据token数估算剩余额度。

主窗使用水墨页头与同色详情滚动条。最小化、最大化／还原和关闭由页头右侧的自绘按钮提供。页头空白处可拖动和双击。运行中的正式实例和其他正式包共享单实例锁，直接打开另一份程序会唤醒已运行的窗口。默认窗口优先一屏展示总览，宽屏最大化可查看逐盘温度、进程补充数据和近期事件。CPU 与物理内存的当前值在窗口和托盘每 3 秒刷新。提交内存、进程、历史和告警使用完整采样，默认 30 秒。显卡和磁盘温度使用 60 秒慢采，驱动未返回读数时显示未知。本版无需额外安装温度库或驱动。

在「更多指标」选择「桌面帧间隔」，默认看最近一小时。尖峰表示桌面有更新时两帧之间隔得较久，悬浮可查看开始时间，用来对照烛龙或 Windows 事件日志。静止或无法采样时曲线留空。

总览的阴鱼深墨面积和外环弧长都表示提交内存占比。「外观」提供山水显隐、换景和动效开关。桌面展示内容禁用拖选，搜索框内仍可选字编辑。切换「进程占用」的提交、CPU 或 I/O 时，墨晕在面板内展开。

在桌面「AI 账本」点击「更新账户用量与额度」，通过当前登录的 Codex CLI 读取账户累计、近期日用量和套餐窗口的已用、剩余及重置倒计时。本机请求累计与会话快照仍可独立读取。缺少 Codex CLI、未登录或接口不可用时，页面标明数据状态和来源。

AI 账本也支持 Kimi Code 和 GLM（ZCode）。Kimi 默认目录沿用当前登录，点「账户来源设置 → 登录第二账号」可为第二个账号使用独立目录。两个账号可分别更新套餐。原共享目录会话保留在待归属账本，第二目录的记录可单独查看。GLM 从本机 ZCode 读取已完成请求。套餐查询需在同一设置页选择国内／国际并保存 Coding Plan API Key，Key 只保存在 Windows 凭据管理器。

DeepSeek 使用同一账户来源设置保存官方 API Key。选择「DeepSeek」并更新余额，可按币种查看 API 钱包的可用、充值和赠金余额。[DeepSeek 官方余额接口](https://api-docs.deepseek.com/api/get-user-balance/)

[桌面挂件交互原型](prototypes/desktop-widget/index.html)可离线对照朱印、太极和墨条，体验左右贴边、昼夜切换和系统／AI 两种展开页。

[盘龙柱原型](prototypes/desktop-widget/dragon.html)以空心盘龙柱显示屏边的物理内存占比。悬停展开系统读数，点击可固定面板，拖动可以换边。

在托盘右键菜单选择「显示桌面贴边挂件」，即可把小龙和内存进度条放在屏边。挂件默认关闭，开启仅在本次运行有效。拖动边条或展开后太极以外的区域，松手吸附到左侧或右侧。点击太极播放墨影扩散并整理符合条件的白名单后台进程，无需逐项选择。挂件底部显示本次专用工作集减少量或跳过结果。没有可处理的进程时显示「无可整理后台进程」。

双击朱印托盘图标打开面板，悬浮提示显示 CPU、物理内存和提交内存。托盘的水墨菜单提供打开、挂件、整理内存、设置、重启和退出。挂件右键可打开烛龙、整理内存或仅在托盘显示。浏览器、暂停或静音、限流、登录自启、守护、AI 账户、导入导出和检查更新集中在「设置 → 工具与维护」。检查更新从 GitHub 正式发布查找较新版本，下载对应包到程序目录的 `updates`，校验后询问是否应用。

服务重启会在停止前取得完整操作权限。通知中心收件和专用测试服务的重启及取消恢复已有实测。长稳观察结果与交接进度见[替代功能验收](docs/完整替代功能验收.md)。

## 旧版项目背景与功能记录

以下v1.6说明及Python启动方式保留为历史记录，不作为新版运行步骤或性能承诺。

监控平时看不到的系统数值（**commit 提交内存水位**、物理/页面文件三层内存、CPU 总占用与单核峰值、磁盘 IO 速率），白名单**自动处置内存泄漏进程**，异常时 Windows toast 主动通知，配套烛龙风**昼夜双态**本机面板回溯历史。

诞生于一次真实事故：两个后台软件泄漏 40GB 提交内存，导致游戏闪退、桌面黑屏——烛龙把那次事故的取证与守护能力常态化。

## 旧版特性（v1.6）

- **温和资源回收**：白名单后台进程**内存整理**（EmptyWorkingSet 回收物理内存，不杀进程不丢数据；内存无压力不折腾）；泄漏服务**温和重启**（stop→start 白名单制，出厂只告警）——关键进程（系统/安全软件/SYSTEM 账户/前台窗口）多重信号自动识别并跳过，识别不了的一律不动（fail-closed）
- **限流错峰绑核**：多规则各切独立核组不再叠核（spread:N），配单核饱和告警（最忙核打满而总占用不高 = 多进程挤核，一眼识别）
- **E5 国风昼夜面板**：宣纸/漆器手卷双态，三栏界格布局（左大户榜+限流设置+温和处置 / 中六分区 / 右朱批记事），固定高度绝对量程图表、数据条判词、焦点待办**二次确认直接处置**、干支四季动态题跋
- **限流器**：给烧核进程戴镣铐（优先级+绑核，全运行时属性），出厂/覆盖双层规则，托盘一键开关与恢复默认，已施加清单持久、随时可全量还原
- **进程大户榜**：CPU/IO/commit 三类大户一次遍历产出，卡顿元凶一眼锁定


- **看不见的数值持续记录**：commit charge（虚拟内存总额度水位，游戏闪退/桌面黑屏的头号预警指标）、物理内存/页面文件分层、CPU（总占用+单核峰值+大户进程）、磁盘 IO（读写速率+最忙盘+IO 大户，覆盖"安全软件扫描外接存储致卡"场景）
- **白名单自动处置**：泄漏进程超阈值 → 七步安全链确认后自动结束 + toast + 事件落库；频次熔断防拉锯；其余异常仅通知；红线告警环比抑制（稳态超线进程不刷屏，涨超 1GB 才重报，跌破红线即复位）
- **烛龙风面板**（127.0.0.1 只读）：睁眼/闭眼昼夜双态主题、24h/7天/30天区间切换、全中文标注、事件语义标记（处理/提醒/待处理+推荐处理思路）、悬停十字线全图联动、龙形 Logo 与朱砂印章
- **轻量与自愈**：常驻内存 <80MB、空闲 CPU <1%、不上传监控数据（默认仅网关与公网 DNS 的 ICMP ping，可关闭）；计划任务自启 + 每 5 分钟心跳看门狗；单实例互斥；托盘四态图标
- **可扩展**：指标采集器/规则/动作三类扩展点，扔文件进目录即生效，schema 永不动

> 边界说明：内存整理只降物理内存（working set），不减 commit（页面文件）——泄漏进程的根治仍走白名单 kill 链；页面文件由 Windows 自动回收，烛龙不做任何页面文件操作；磁盘/注册表清理属非目标，永不做。

## 旧版架构速览

```
单进程三线程：主线程托盘(pystray) / daemon 采集循环(30s) / daemon 只读面板(http.server)
collectors ──► SQLite(WAL 窄表) ──► rules ──► actions
  指标插件         通用 schema          数据式规则      kill/toast/mem_trim/restart 自降级
```

- 数据：SQLite WAL 通用窄表（30 天保留自动清理），扩展指标不改表结构
- 安全红线：面板仅一个令牌守卫的 POST /api/action 动作通道（零配置写端点）、只绑 127.0.0.1；kill 白名单 + NEVER_KILL 入口硬阻断 + PID 复用竞态防护；配置 `path_contains` 的条目执行 fail-closed 路径校验；无提权、无注入
- 依赖仅 4 个纯 pip 包：psutil、pystray、Pillow、winotify（面板用标准库 http.server，无 Flask）

## 旧版排障速查

| 症状 | 处理 |
|---|---|
