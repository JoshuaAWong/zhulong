# 烛龙 · Windows 系统监控托盘

监控平时看不到的数值（commit 虚拟内存等），白名单自动处置泄漏进程，异常主动通知。
需求与设计详见 docs/，本 README 只讲安装、使用、排障。

## 安装
双击 `scripts/安装.bat`（自动装依赖 + 注册开机自启与 5 分钟看门狗 + 立即启动）。
前提：Python 3.13（安装脚本已写死路径，与系统里其他 Python 版本互不干扰）。

## 日常使用
- 托盘：绿 <70% / 黄 70~85% / 红 ≥85% / 灰=心跳异常；悬停看数值；双击开面板
- 面板：http://127.0.0.1:8890 —— 烛龙风昼夜双态（眼睛按钮切换，睁眼为昼闭眼为夜）；区间切换 24小时/7天/30天；全中文标注（含含义说明）；内存三层分离（物理内存/提交内存/页面文件）+ CPU（总占用/单核峰值/大户）+ 磁盘 IO（读写速率/最忙盘/IO 大户）；曲线带 70%/85% 阈值虚线；悬停任一图表十字线定位并联动全部图表，24h 区间曲线带事件标记点（处理/提醒/待处理/静音，悬浮看详情）；待处理事件红色重点提醒并附推荐处理思路；事件时间线带回溯徽章；30 秒自动刷新
- 暂停自动处置 5 分钟：托盘右键 → 暂停 5 分钟（采集照常，仅静音动作）
- 退出：托盘右键 → 退出（看门狗不会复活它；重启电脑后恢复自启）

## 排障
| 症状 | 处理 |
|---|---|
| 安装时安全软件弹窗 | 点"允许"并勾选不再提示；建议把本项目目录加入信任区 |
| 托盘图标不出现 | 任务管理器查 pythonw.exe；看 data/logs/zhulong.log；勿用管理员身份跑计划任务 |
| 通知收不到 | Windows 设置 → 系统 → 通知：总开关开启、勿扰关闭；烛龙通知开关开启 |
| 面板打不开 | data/logs 查端口冲突；确认只绑了 127.0.0.1:8890 |
| 面板数据陈旧不更新 | 看托盘图标是否变灰（采集异常）；查 data/logs/zhulong.log；杀 pythonw 由看门狗拉起 |
| 游戏闪退/卡顿 | `python -X utf8 -m zhulong.diag --hours 6`，把输出发给 AI |

## 手动验收清单（对应需求文档 AC-1~7）
1. AC-1 泄漏处置：把 config.py 里 HYPHelper 阈值临时调到 0.5 观察 kill+toast+事件，测完改回
2. AC-2 无副作用：被杀后重开 HoYoPlay 正常
3. AC-3 自愈：结束 pythonw 进程，≤7 分钟自动拉起，且实例唯一
4. AC-4 退出语义：托盘退出后看门狗不再拉起；重启后自启恢复
5. AC-5 数据对齐：面板数值与 PowerShell Get-Counter 对齐（误差 <1%）
6. AC-6 扩展：新建 collectors/mock.py（含 COLLECTOR dict）重启后面板出现新指标
7. AC-7 资源：挂机 24h 内存 <80MB、空闲 CPU <1%
