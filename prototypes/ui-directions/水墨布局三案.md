# 水墨布局三案：云岫、砚池、游廊

2026-11-07。用户要求一步一步完成 UI 选择：继续水墨风、有设计感、选中模块有效果、边界柔和不锐利。本轮是完整布局候选，未替用户定版，也不改变已有架构决策。

入口：[可交互对照](ink-layouts.html)。顶部选择 A / B / C；右上切换昼夜；点导航、指标和模块“关注”比较反馈。三版同数据、同素材，避免把不同数据或不同画作误当成布局优势。URL 可用 `?layout=mist`、`?layout=inkstone`、`?layout=gallery`，并附 `&tone=dark` 打开夜间。

## 设计计划

先核对既有 HTML、app.js、ink-ui.js 和两层 CSS。新增 ink-layouts.html/css/js，复用原来的样本、导航、详情、图表和昼夜场景属主；独立脚本只维护候选布局和模块关注状态，原页面保留。

原设计复核：保留 B/B3 的水墨、圆润和功能分区，只对导航位置、主次比例与选择反馈作三种演绎。删去额外装饰编号、重复卡片边框和持续闪动。山水沿用已认可 v7，v3 仍可换景，不另开画风选型。

自查（非独立把关）：中档、可逆的静态原型，预计新增约 400–600 行代码与说明，无新增依赖，不读取本机状态或写入配置。共享交互有现成属主，故只新增布局层，不复制三套业务脚本。HTML 固定样本模板独立保留便于候选对照；CSS 单文件单责且小于 400 行。边界风险为 CSS 叠加优先级与窄屏重排，检查六种组合和响应式规则。实际浏览器视觉与原生 dialog 行为仍待验收；不将模拟 DOM 当作视觉通过。

## 选择反馈

- 主导航：A 以椭圆淡墨托底；B 墨面加短笔；C 柔影衬底。活动页有明确文字与 `aria-pressed` 状态。
- 模块关注：进程、资源趋势、事件三选一；点“关注”或模块内操作会选中该模块，按钮变为“已关注”，底部同时显示名称。关注不改变采样、告警或数据。
- 指标与时段：选中项使用柔和实底；内容随已有图表逻辑切换。
- 进程与资源：点选后保留查看痕迹并打开既有详情，关闭后可看到点选位置。
- 键盘保留清晰的焦点轮廓，不能为了柔和边界牺牲可操作性。
- 布局切换保留当前页面、昼夜、筛选与关注；外观偏好只在当前页面内有效，不写配置。
- 减少动效、手动关闭动效及页面隐藏沿用统一控制；伪元素过渡也关闭。龙身游动仍未实现。

## 验收范围

这一步选择的是主界面布局和反馈语言。三版共享 AI 账本与事件页，托盘、设置、导入/更新流程的精细稿留到方向选定后补齐，不把本轮候选称为整套 UI 定版。

对照图是独立绘制的布局说明，不是浏览器截图。可交互 HTML 才是具体候选实现。既有本地 URL 安全限制不绕过；可由用户在本地浏览器用 Ctrl+O 打开 ink-layouts.html。本轮没有启动正式程序或窗口压力循环。
