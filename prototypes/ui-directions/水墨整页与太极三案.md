# A 布局：整页水墨与太极交互三案

## 设计计划与自查

先核对 A 的 HTML、共享交互、主景和选择反馈。以一个独立入口承载三种整页关系，复用 app.js、ink-ui.js、ink-layouts.js；新增整页装饰层、候选控制和太极组件，不改采集器、业务数据或既有原型。预计新增约 300–400 行代码，按 HTML、整页 CSS/JS、太极 CSS/JS 分工，单文件小于 400 行。

自查（非独立把关）：中档、可逆的 UI 候选；既有 A 属主与素材足够，直接复用优于重新实现导航或生成三套页面。用户后续要求使范围从背景延伸到控件与占比，增加两份单责组件文件；无新增依赖或常驻刷新。风险是装饰抢读、SVG/CSS 样式相互覆盖和模糊层开销，分别以阅读留白、组件作用域与静态装饰控制。浏览器像素、原生焦点和资源开销尚待验证，不以几何/模拟 DOM 检查宣称通过。

## 整页与控件契约

- page-ink 为整个工作面共享的非交互图层，覆盖总览、AI 账本和事件页，pointer-events:none，aria-hidden。山水开关同时关闭头部和扩展装饰。
- 扩展山体与远岸从已有本地长卷通过 SVG viewBox 取景，保持原图比例。v7 取右侧及底部；v3 原景龙身更大，切换时改取右下和最底部，避免重复龙首。原文件不改写。
- 内容区用渐隐留白保护阅读，不给整页或文字施加 blur。导航、指标、时段、进程选择、关注按钮与详情衬底使用连续笔势的 SVG 遮罩，数字和键盘焦点保留清晰边缘。
- A 布局固定；切候选保留当前页、指标、筛选、昼夜和关注。偏好只在当前页面中表达，不写入配置。
- 沿用 180–230ms 用户触发的反馈，减少动效、手动关闭及隐藏暂停仍由共享逻辑负责。模糊半径、遮罩和太极图不做无限动画；无新增轮询或永久帧循环。龙身游动仍未实现。
- 静态滤镜仍有渲染成本；正式 WPF/WebView2 迁移前需按 P0 测量，必要时对纯装饰预渲染，不在本轮承诺内存或帧率。

## 太极占比契约

- 主水位固定演示提交内存 26.4 / 48.0 GB = 55%，对应上限余量 45%；CPU 14%、GPU 6% 使用同一风格的小组件。磁盘/网络是速率，保留原数值与趋势，不虚构百分比分母。
- 强调色数据弧从顶部开始顺时针，pathLength=100，弧长严格按百分比；端帽为 butt，避免小百分比被圆帽夸大。浅色底环表示完整量程，未覆盖部分是余量。
- 中央阴阳图固定等分，只是风格元素；读数以外部数据弧和数字为准，并通过 aria-label/title 解释口径。主水位不随下方趋势图的指标切换改变。
- A1 外围淡墨晕仅为装饰，精确细弧在其内；A2 鱼眼置于足够长的弧内，0%/100% 不绘制不存在的分弧鱼眼；A3 加宽弧带并给出四向参照，不改变量程。
- 候选组件不接入真实采集数据，不把演示占比称为当前电脑状态。
