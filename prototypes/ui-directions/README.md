自查（非独立把关）：新增独立 HTML/CSS/JS 与本说明，展示同一组数据，主程序与 P0-A 保持原样。无新依赖、无数据读写；低开销通过无定时轮询、无永久帧循环和可停动效体现，资源实际数值不作承诺。
