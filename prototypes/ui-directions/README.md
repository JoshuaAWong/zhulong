## 设计依据与范围

用户已确认首版为观察版：系统监控、历史告警、托盘面板、一个 AI 工具统计、基础主题动效；安装版和便携版共同交付。历史方案为新库起步、用户主动选择一次性导入，原记录保留。AI 提供器顺序待答复，原型以“示例工具”表达，不暗示已实现某提供器。

沿用烛龙龙标、昼夜双态、左排行/中监控/右记事、安慎危语义；观察版只有查看与筛选，没有 kill、清理或服务重启操作。数据全部为固定演示样本，烛龙自身 0.06 GB 等数字仅为排版，绝非实测预算。

按 frontend-design 技能先拟定三套设计，再构建独立原型；共享数据与交互，分别改变材料、层级和区域组织。

A  龙标/品牌 ── 导航
   安字判词             提交量/提醒

   排行 │ 资源条 → 曲线 │ 事件面板
C  品牌 ── 导航
   圆弧状态摘要 / 浅色龙纹
   排行 │ 开放曲线       │ 书页式记事
        │ 资源分区/账本  │ 观察说明

设计复核：A 的纸墨和三栏来自已认可的 E5，不把它当作泛用模板；B 用仪表与区域顺序区分，避免仅做 A 的深色皮肤；C 保留信息三栏，采用开放图面和独立书页，减少装饰。三版均不添加营销内容、无意义编号、满屏循环动画或远程字体。

自查（非独立把关）：新增独立 HTML/CSS/JS 与本说明，展示同一组数据，主程序与 P0-A 保持原样。无新依赖、无数据读写；低开销通过无定时轮询、无永久帧循环和可停动效体现，资源实际数值不作承诺。

## 可试交互

- 切换三种方向及每版昼夜主题；主导航进入系统、AI 账本、事件页。
- 提交/物理内存/CPU 切换，24 小时/7 天/30 天切换；百分比曲线固定 0–100% 量程，趋势形状为演示示意，不用于回推事件精确时刻。
- 内存/CPU 排名、进程搜索与详情，事件筛选、记录详情及 Escape 关闭弹窗。
- 230 ms 用户触发过渡；支持关闭动效及系统减少动效，隐藏页面取消当前动画，无后台刷新循环。
- “本页偏好”只标记当前页面，不写配置、不自动向对话发送消息。
