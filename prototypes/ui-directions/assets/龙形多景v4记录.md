# 龙形、姿态与多背景 v4

2026-11-07 追加：按用户要求对照经典龙形、允许肢爪自然遮挡，并调整长度与盘绕姿态。当前 v4 有两组昼夜背景：松崖长游／江湾回环、云岫盘龙／寒汀远行。在“外观 → 换景”手动切换，切换昼夜保留当前组，三页共用；不自动轮播、不写入配置。四幅均为静态候选，完整视觉与龙身游动仍未验收。

## 对照依据

《本草纲目》龙条的“九似”包含“爪似鹰，掌似虎”，支持传统画龙的掌爪特征，但不是每幅画都必须展示所有肢爪。[原文](https://zh.wikisource.org/wiki/本草綱目/鱗之一)。陈容《云龙图》的作品说明同时描述强健龙爪、S 形盘旋与云中隐现，[中国文联作品说明](https://www.cflac.org.cn/ArtExchange/yishujiaoliuzazhi2018/yishujiaoliuzazhi2018/201812/t20181225_430413.htm)；本轮以作品说明核对，不声称新做了原图高清肢爪观察。

原典烛龙与后世传统画龙须区分：《山海经》描述人面蛇身、赤色，不能据一般龙形断言烛龙必须具爪。[原文出处](https://ctext.org/dictionary.pl?char=%E7%87%AD%E9%BE%8D&if=en)。本项目沿用用户认可的水墨龙形并借用昼夜意象，是艺术化设计，不宣称原典复原。

## 当前图像判断与修订

v3 的头角、须、鳞身可辨，但没有明确的肢掌爪连接；夜景回环较密。v4 让近侧肢从肩位经肘腕到掌爪，其他肢体随云和身体遮挡，不以“全部露出”验收。长游强调细长收尾，盘龙强调环内空隙和可追踪的身体走势。已目视查看四幅：均可辨近侧前肢及爪，盘龙环内空间更清楚；日间盘龙前爪较醒目，仍待用户评估，不声称造型定稿。
