## 已认可局部小样的实际提示词

```text
Use case: style-transfer.
Asset type: 烛龙界面画风验证，单幅龙头与颈部的局部笔墨小样，仅供预览。
Input image 1: 现有日景的角色与左向姿态参考。只借用东方长龙的身份、角形、沉静眼神和朝左方向；它的细丝鬃毛、精修边缘和光滑立体明暗正是要纠正的部分。
Primary request: 重新用中国画毛笔绘制龙头及连接的一段龙颈，近景横幅约 3:2，完整角须留在画内，龙头朝左，颈部向右舒展。白灰纸底，少量淡墨云气，不画完整山水，不做拼贴对比板，无文字。
Style/medium: 有筋骨、有笔锋的传统纸本水墨写意。让观者看得出每笔毛笔怎样按下、转折、提起：额骨、眉、鼻梁、嘴角与下颌由明确而连贯的中锋线与侧锋墨面构成，线宽和墨量随运笔改变；部分落笔墨厚，收锋自然变细，局部干笔内部留白。鼻与眼用少量凝练的深墨点醒，脸颊与腹侧主要靠浅墨和纸白成立，不能靠光滑渐变塑形。
鬃毛按几组有方向的长笔和宽窄相接的墨面绘出，避免一根根精修发丝；两三根主须舒展连贯，有提按与收锋。角的分叉简洁有力，颈部保留几组随形转动的鳞纹，细节集中在神情和结构。保留成熟沉静的龙，不画成粗暴怪兽。墨线可清楚但绝不工整等粗，墨边自然有干湿差异，不做全面柔焦。真实手绘感来自笔画本身，不来自破损、脏污或随机噪点。
Avoid: 光滑龙雕塑，游戏概念设定，摄影式动物毛发，整圈精致细描边，CG体积光，边缘高光，塑料感，密集发丝，均匀重复鳞片，整体模糊，纸张做旧纹理，刻意断裂碎笔，喷溅装饰，印章，水印，文字。
```
