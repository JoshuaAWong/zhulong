# 烛龙水墨主景 · 名家笔墨参考

日期：2026-11-07。范围：用户认为当前风格仍有生成感，要求参考名家山水与动物画的笔锋细节。本记录区分馆藏事实、原图观察和用于烛龙的设计判断；不把生成图称为真人手绘。

## 当前结论

v2 已满足昼夜龙向和地貌分别绘制的形式要求，但用户仍不满意画风，保留为候选，不能记为视觉定稿。本轮暂停继续生图，先修正绘画方式：问题不仅是轮廓锐利，还在于细节过于均匀、体积依靠连续明暗塑造。把边缘全部柔化或加纸纹，仍会保留数字插画的底子。

清楚的笔锋本身不是问题。原作同时存在劲健线条、枯笔空隙、湿墨渗化和大片留白，关键是这些变化参与造型。笔势连续也不等于全身一圈等粗闭合线，更不等于到处抹平；每段线应有可读的起笔、转折与收束。

## 原作与观察依据

### 陈容《九龙图》：细密龙鳞与云墨隐现

- 来源：[波士顿美术馆馆藏目录](https://collections.mfa.org/objects/28526)，1244 年，馆藏号 17.1697；实际放大查看使用[芝加哥大学东亚艺术中心长卷档案](https://scrolls.uchicago.edu/view-scroll/49)。馆藏页遇验证页面，未绕过；大学档案明确标注藏馆和图像来源。
- 本轮实际查看：长卷整体与其中一龙的龙首、躯干、云层和山石局部；不是对整卷每一笔的鉴定。
- 图像观察：龙鳞有成组清晰线描，形状与疏密随身形改变；须线较长，云墨成片，龙身在云中隐现。山石的折线和干笔，与湿墨云团形成不同质地。
- 用于烛龙：龙首、颈部和局部鳞片可以精细；腹侧、尾段和云层承担虚实转换。撤回早先提示词里“一律不要逐片描鳞”的过度限制，改为避免等距平铺、机械重复和整身同等锐度。丰富细节应有节奏，不靠甲片高光堆砌。

### 石涛《山水册》：山石的皴擦与疏密组织

- 来源：[大都会艺术博物馆 Landscapes](https://www.metmuseum.org/art/collection/search/49179)，约 1690 年，纸本水墨设色，八开，馆藏号 1989.363.154a–h。
- 本轮实际放大查看：册页 a、b 的树石、岸线、淡染和留白。
- 图像观察：山石有不均匀的转折轮廓与斜向干笔，深墨点簇有大小和聚散变化；浅染铺成块面，纸白仍是水和空气。并非把所有远近物体都包在一层均匀雾气中。
- 用于烛龙：主山、近石、远峰各有不同笔触密度；松针、点苔、皴笔分别组织，沿山势落笔。留白形成水路和呼吸，不用空白处自动补云，也不用遍布全图的颗粒制造“古旧感”。

### 八大山人《鱼石图》：浓墨、简线和纸白共同塑形

- 来源：[克利夫兰艺术博物馆 Fish and Rocks](https://www.clevelandart.org/art/1953.247)，17 世纪中后期，纸本水墨手卷，馆藏号 1953.247。
- 本轮实际放大查看：鱼身、腹线、眼、鳍尾局部。
- 图像观察：背部浓墨里保留不规则干笔空隙，腹部主要留白，边线有粗细轻重；眼部一处深墨就能集中神情，鳍尾的笔触方向直接参与造型。
- 用于烛龙：腹背的区别不必靠平滑渐变，局部用墨面、结构线和纸白建立形体；眼神作为小而明确的视觉焦点。借鉴用笔方法，不把用户要求的丰富山水简化成空疏小品。

### 齐白石虾：补充馆藏说明，不冒充高清细读

[大都会《Shrimp》](https://www.metmuseum.org/art/collection/search/49648)（1927，馆藏号 1986.267.212）的馆方说明强调书法性的笔墨组织、结构与墨色变化。本轮页面仅有小图，未进行高清笔锋观察，因此只将其作为文字依据，不据此断言具体局部的运笔顺序。

## 下一轮绘制准则

| 对象 | 保留或增加 | 避免 |
|---|---|---|
| 龙首、须、鳞 | 有提按转折的长线；清楚处成组集中；鳞纹随身体转向 | 全身等粗描边、重复甲片、发光轮廓、均匀锐化 |
| 龙身 | 墨面、结构线和留白共同塑形；在云中失而复见 | 光滑雕塑明暗、圆管般的渐变、每处相同的柔焦 |
| 山石与松林 | 皴笔顺山势；点苔有疏密；近景细、远景简 | 每块石头同样精细、到处碎纹、统一刷噪点 |
| 云水 | 湿墨成片与纸白相接；水道有明确走向 | 云层填满空处、烟雾滤镜、整体模糊 |
| 昼夜关系 | 日间向左游龙与层峦松瀑；夜间向右回游与江湾洲渚，各自构图 | 同图换色或镜像；夜间依靠白色描边发亮 |
| 界面 | 沿用 B 布局、圆润外壳和开放信息层级；装饰让出文字区域 | 把纸纹铺在数据正文上、为装饰降低可读性 |

主参考采用陈容的龙与云墨、石涛的山石笔势；八大和齐白石用于理解以笔塑形与浓淡取舍，不将多位画家的外观机械拼贴。

建议下一次先验证龙首与一段鳞身、松石与云水两组局部，再扩成两幅不同构图的长卷。观察笔触的方向、粗细和干湿能否读出来，丰富细节是否有聚散，缩到界面尺寸是否仍有主次。当前仅确定研究后的建议，尚未生成这些局部或取得用户视觉验收。
