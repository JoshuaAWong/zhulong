# 烛龙 P0-A 界面对照原型

可丢弃实验，不是新版烛龙。仅生成 300 点曲线及 50 行测试列表，不访问旧数据，不执行系统处置，也不注册常驻服务。

计划与结果：[P0 界面对照验证](../../docs/P0界面对照验证.md)。

## 构建与运行

需要 .NET 10 SDK、Node/npm、Python 和现有 psutil，以及 WebView2 Runtime。所有版本见项目锁文件；前端只生成本地静态文件，运行时无 Node 服务。

在本目录构建：

~~~powershell
npm ci --no-audit --no-fund
npm run build
dotnet build -c Release -p:UseSharedCompilation=false
~~~

默认不执行重复开关。以下命令只用于主动安排的单次面板检查及缺失资源验证；本次用户桌面已被压力测试干扰，后续 100 次实验须移到独立测试会话或虚拟机：

~~~powershell
python -X utf8 prototypes/p0-ui/run.py --dotnet <SDK目录>/dotnet.exe
~~~

本次项目专用 SDK 位于忽略目录 out/p0-tools/dotnet-local；如使用该位置可以省略 --dotnet。也可指定 --cycles 2 --seconds 8 做短检查，此结果不能替代 100 次验收。额外加 --capture 会由面板自身导出 panel.png，仅用于单独视觉核验；正式性能测量不要启用，以免截图分配影响结果。

运行会短暂显示不抢焦点、不加入任务栏的窗口；请不要手动关闭或最小化被测窗口。输出位于 out/p0-ui/<运行时UTC时间>/，含逐阶段样本、事件、汇总和 WebView 测试缓存。

## 口径

- 资源统计是原型宿主及自有子进程之和；working set 求和可能重复计入共享页，并非独占物理内存；CPU 另报单核等效和全机归一化值。
- 各阶段前 5 秒不计稳定均值。每个阶段默认 20 秒，是短期初筛，不是长时间稳定性报告。
- I/O 原始字段是每次采样时仍存活进程的累计计数，进程退出后会下降，不能用首尾相减当作整个实验的总 I/O。短命进程的末尾 CPU 也可能漏采；循环阶段不据此给性能排名。
- WPF 合成回调和 Web 两次 requestAnimationFrame 回执是刷新延迟代理；不能声称是用户输入的真实 P95 或显示器实际呈现时间。
- 只用合成数据与基本折线；未包含真实 AI 解析、数据库、托盘、挂件或完整国风设计。
- 正常关闭不调用 GC.Collect、不结束浏览器；外部检查失败后才清理本轮残留，失败记录不会改成通过。
- WebView 用户目录按每次运行隔离，同一次循环复用目录。首开与重开可比较，不能称作清空系统缓存后的冷启动。

本轮 100 次正式对照因任务栏卡顿中断，不能据此宣称 P0-A 验收通过。停止后用户确认桌面恢复；已关闭默认循环并设置 ShowInTaskbar=false，但这一修订本轮只做编译检查，未再次启动窗口验证。
