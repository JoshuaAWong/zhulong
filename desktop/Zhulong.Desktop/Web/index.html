外环计量 当前采用

墨面消长 探索方案

占用 55% · 余量 45%

内外圈一同旋转，数字保持水平。占用越高转速越快，自然最高十倍，悬停再乘三；墨面方案保持静止便于比较。

四象是循环，不是负载刻度
