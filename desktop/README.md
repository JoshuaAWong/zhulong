# 烛龙独立桌面版

新版采用一个 .NET 后台、WPF 托盘及按需启动的 WebView2 水墨界面。Core、Runtime、Desktop 分属三层。完整功能与证据见[替代验收](../docs/完整替代功能验收.md)。

## 使用

双击 Zhulong.exe 打开主窗口。程序、主界面和系统托盘使用 C 朱印，贴边挂件顶部使用 A 玉龙。关闭主窗口会释放 WebView 并保留托盘。双击托盘或再次运行 EXE 可唤醒同一实例。主窗口 Ctrl+, 打开设置，Ctrl+Q 正常退出，托盘也可退出。

总览优先单屏显示进程、趋势、事件及处置。使用趋势区指标下拉查看详细资源，使用主导航打开AI账本和事件记录。主窗口边框、标题栏及详情滚动条随昼夜配色。

设置分基础页/高级JSON，保存后下次启动生效。自动处置、限流、自动整理默认关闭；手动工作集整理和显式服务操作在面板“操作与待处置”中，必须原生二次确认并重新检查安全条件。工作集整理不等于减少commit。服务名单默认空；安全/系统关键目标拒绝。

托盘提供暂停自动处置及提醒5分钟、独立静音、恢复、限流开关/恢复默认、原生设置、旧历史导入、诊断、自启守护与重启。暂停期间仍采样、评估规则并保存历史，不累积旧自动动作；已在途服务完成安全补偿。

“在浏览器打开新版”才启动127.0.0.1:17631的Kestrel入口，可从托盘关闭。桌面面板不依赖HTTP。浏览器复用同一后台与固定动作，不开放配置写、CORS或任意文件/命令。

首次CPU/IO差分保持未知；系统默认30秒、慢源60秒、AI60秒、限流120秒。慢源记录原采样时间，超过180秒显示旧/未知；权限不足和设备不支持不会变成零。GPU当前仅NVIDIA首卡。进程CPU为占整机0–100%，提交内存与物理工作集分列。

## 数据和更新

默认程序目录data：monitor.db为系统历史、ai.db为Codex账本、legacy.db为主动导入旧记录，settings.json为新版设置，actions.json保存频次与原始进程限制，cache/WebView为独立浏览器缓存。日志有大小上限，新监控原始数据默认保留30天；主动导入旧记录不自动清理。

“导入旧版历史…”只读用户选中的旧烛龙SQLite库；原时间、标签、指标与事件保留，旧无时区时间按本机时区解释，取消/失败整批回滚。同一路径只完成一次，不自动导入或修改旧配置。TokenTracker旧账本导入尚未实现。

安装版和便携版共用运行产物。ZIP 只分发运行目录，安装器为当前用户创建程序、快捷方式和卸载项。手动运行安装包前需先退出烛龙。卸载保留 `data`、`updates`，仅移除指向本安装路径的新版任务。

从朱印托盘选择「检查更新…」，确认下载后在 `updates` 获得已校验的安装包或 ZIP，再确认应用。更新期间采样会短暂停止，更新后从原路径恢复。0.2.6 或更早的版本可正常退出后手动安装 0.2.7。发布端用正式版本号和同版本的两种包名，供新版识别。

从托盘的“登录后后台自启…”和“5分钟存活守护…”分别设置。登录自启只驻留托盘，正常退出写意图标记，守护会尊重主动退出。任务变更失败时补偿旧任务并回读。失活恢复只允许同安装、同用户/会话、PID/创建时间匹配的上一代新版，按采样间隔判断过期且10分钟冷却；缺字段/损坏记账拒绝终止。不处理旧Python。服务崩溃恢复与长期稳定性仍有验收边界。

## Codex统计

请求账本、桌面累计快照分列，不相加；输入含缓存、输出含推理，子集不重复加总。额度是来源快照，展示重置时间和剩余等待，不从token推算套餐余额，到期等待新记录确认。

每轮最多16MiB日志正文、64文件批、256目录项及256会话元数据行；快采不等待AI。SQLite同一只读连接用data_version确认外部commit，失败不消费水位，停止释放源连接；无变化日志正文0字节不等于元数据零IO。超4MiB单条记录保持可见错误与原游标，后续正常来源继续。Kimi/ZCode及账户在线额度未实现。

## 构建与验证

仅开发机需要Python与.NET10 SDK；使用者不需要源码、Python/Node或系统.NET，WebView2 Runtime由系统提供，缺失只显示说明。

~~~bat
python -X utf8 desktop/build.py
python -X utf8 desktop/build_installer.py --task-cleanup
dist\Zhulong\Zhulong.exe --self-test out\desktop-tests
dist\Zhulong\Zhulong.exe --diagnose out\diagnostics.json
~~~

构建输出dist/Zhulong、同版本便携ZIP和setup.exe。安装编译器仅开发期使用Inno Setup；不加入运行依赖。自包含发布包含.NET/ASP.NET Core框架，Kestrel仅浏览器入口启动时创建；新增框架用于成熟HTTP协议和免HTTP.sys URLACL配置，不能据此宣传常驻资源达标。

正式C#与UI源码在desktop，构建不引用prototypes业务源。分发排除data、源码和PDB，附SHA256清单及[TokenTracker许可](Zhulong.Runtime/Providers/AI/THIRD_PARTY_NOTICES.md)。

本轮最终发行EXE234项整合检查、32项受控原生helper检查、旧版17/17模块通过；原始证据不随程序分发。最终655文件SHA部署、安装/升级/卸载保留data与updates、约60秒慢采及原生历史tooltip已实测；真实托盘菜单点击、通知送达、真实服务成功与24小时仍未验收。实际窗口、安装升级、长期资源边界以[完整替代验收](../docs/完整替代功能验收.md)为准。自建helper不进入发行包。

当前独立运行目录为%LOCALAPPDATA%/Programs/Zhulong。旧版保留作独立基线；真正交接时先正常退出旧版以还原它施加的限制，再启用新版对应自动功能。
