# 独立桌面运行版（2026-11-08）

## 已确认范围

用户要求先做能打开窗口、挂托盘的新UI程序，替代浏览器式入口，并明确源码/运行程序分离。用户随后明确：做全新运行版，旧程序不要关联或修改。因此本轮新建.NET桌面宿主、原生采样、新库及受限页面桥；不连接旧后台API，不修改旧Python代码，不改旧数据或自启。

源码：[desktop](../desktop/README.md)。构建：dist/Zhulong；运行目录：C:/Users/Administrator/AppData/Local/Programs/Zhulong；分发：dist/Zhulong-0.1.0-preview-win-x64.zip。运行目录内自包含.NET Runtime、程序集和Web静态资源，没有py/cs/csproj/pdb或开发仓库依赖。当前为便携预览，安装器与正式双形态发布门禁仍待实施。

## 方案把关

自查（非独立把关）：新功能大档。已选.NET/WPF/WebView2、SQLite，复用已完成Codex核心，不新引入Python或Node运行进程。单个新版宿主管理独立托盘、30秒采样与一分钟AI任务；窗口按需创建销毁，只有可见面板运行前端刷新与动效。前端复用已选水墨原型的设计资源，数据适配独立，不重写已确认视觉风格。

主要风险：WebView实际成本、冷历史扫描、异步退出、只读来源覆盖；分别通过窗口关闭/进程树观察、4MiB批次与16MiB正文预算、不重叠刷新和取消等待、未知/快照标识验收。目录发现和state快照未做真正增量，后续仍需计量。磁盘/GPU/网络及旧动作尚未迁移，不用演示数字代替。

## 实现契约

- Program唯一新版实例、托盘、窗口和退出属主，使用新版独立mutex/event名。没有自启或看门狗接管旧版。
- SystemMonitor仅Win32/PInvoke与Process只读；CPU差分首空、单进程工作集排行。MonitorStore样本/跨阈值事件同事务，新库不自动删除历史。
- DataHub系统/AI独立任务；面板查询只读缓存和新库，AI手动刷新与定时刷新不重叠，退出等待活动读取完成再关闭库。
- DesktopWindow仅可信本地虚拟域名入口，随机窗口token和固定query白名单；禁止外跳、弹窗、下载和权限请求，不开放任意文件/命令/配置写。无HTTP监听端口，无旧网页接口。
- 关窗Dispose WebView，托盘和原生采样继续；托盘退出停止任务、关闭库和NotifyIcon，旧程序不受影响。
- 运行数据在独立程序目录data；便携ZIP与manifest排除data，更新保留数据。源码与运行目录无链接，无全局PATH或系统.NET安装改动。
