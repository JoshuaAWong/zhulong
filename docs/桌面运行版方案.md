# 独立桌面运行版（2026-11-09）

用户当前优先目标是先完整上位替代旧版，兼顾可靠性、资源开销、稳定性和已选水墨动效。0.2.0-replacement为完整功能承接候选；旧Python程序、原库和旧任务保持独立，未以桥接旧后台充当重构。

当前范围、模块、门禁和证据统一由[完整替代功能验收](完整替代功能验收.md)维护；[桌面使用与构建](../desktop/README.md)面向运行者。0.1预览的实际记录保留在[桌面运行验收](桌面运行验收.md)，不能拿旧测试数字代表当前包。

## 方案把关自查（非独立把关）

本次为核心/schema/生命周期的大档新功能。保持模块化单体：Core无平台依赖，Runtime拥有采集/规则/动作/存储/AI，Desktop只管理Windows生命周期、原生设置、按需界面和受限桥。当前已选静态HTML/CSS/JS迁入正式Web源码，不为框架迁移重新设计视觉或添加Node后台；React/TypeScript工程尚未落地。

复用旧语义与安全约束作为对照，正式实现为.NET/native API；不复用旧Python运行时，不改旧源。对比继续Python、纯WPF与混合面板后，当前继续WPF/WebView2；完整同内容视觉资源预算仍需P0定标，不能以框架名认定更快。

浏览器入口按需使用Kestrel；微软已不建议新项目用HttpListener，避免HTTP.sys权限配置及手写HTTP协议。代价是自包含分发增加框架文件，默认无监听或独立服务；[官方说明](https://learn.microsoft.com/en-us/dotnet/api/system.net.httplistener?view=net-10.0)。安装器采用成熟Inno Setup、当前用户权限、运行互斥检查和同一已校验产物，未自研安装引擎。[官方权限说明](https://jrsoftware.org/ishelp/topic_setup_privilegesrequired.htm)、[运行互斥](https://jrsoftware.org/ishelp/topic_setup_appmutex.htm)。

## 风险与验证

- 慢采、AI、动作不能阻塞快采：独立单在途调度、有界合并队列、120秒限流节拍；已做真实快慢并行与故障注入。
- 所有者/退出竞态：手动命令、导入、任务事务、动作及审计收束后释放数据库；异常UI提示不在退出时追加；阻塞审计替身实测。
- 数据正确性：只读源、真实时间/状态、事务游标、WAL提交版本、一次导入回滚；同长度/mtime来源提交已先复现旧判断漏更再修复验证。
- 配置与动作：原生配置先验证持久化再变更活动限流；原生二次确认、路径/身份/年龄/频次检查；损坏记账不清零；停止拒绝新手动命令。
- 发布回退：运行源码分离、更新前备份自身程序和SQLite一致快照、安装时互斥、升级/卸载保留data；不操作旧Python。
- 未通过不得宣称完成：真实服务重启/通知、完整UI/托盘路径、任意崩溃恢复、24小时及资源阈值仍分别验收；在日常桌面不做反复开关压力循环。
